## 💡 Key Learnings

Building this project helped reinforce key front-end concepts:

1. **CSS Grid Spanning:** Utilizing `grid-column: span 2` and `grid-row` to build irregular asymmetrical grid layouts.
2. **Card Components:** Structuring individual testimonial cards with distinct visual hierarchy (user avatar, header, verified badge, quote excerpt, and full review).
3. **Responsive Design:** Using media queries to gracefully transition from a multi-column desktop layout to a single-column layout on smaller screens.
